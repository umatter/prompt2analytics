# C5.0 Decision Trees

## Method

C5.0 is a decision tree / rule-based classifier that uses information gain ratio for splitting, pessimistic pruning, and optional boosting (AdaBoost-like trials). It is the successor to C4.5 by J. Ross Quinlan.

## R Package Reference

- **Package**: `C50` (v0.1.8+)
- **Function**: `C5.0(x, y, trials = 1, rules = FALSE, control = C5.0Control())`
- **CRAN**: https://cran.r-project.org/package=C50

## R Code for Expected Values

```r
library(C50)
set.seed(42)

n <- 200
x1 <- runif(n)
x2 <- runif(n)
x3 <- rnorm(n, 0, 0.5)
y <- factor(ifelse(x1 + x2 > 1.0, "1", "0"))
df <- data.frame(x1, x2, x3)

# Single tree
model <- C5.0(df, y, trials = 1)
summary(model)
pred <- predict(model, df)
cat("Training accuracy:", mean(pred == y), "\n")

# Boosted (10 trials)
model_boost <- C5.0(df, y, trials = 10)
pred_boost <- predict(model_boost, df)
cat("Boosted accuracy:", mean(pred_boost == y), "\n")

# Variable importance
C5imp(model_boost, metric = "usage")
```

## Rust Test Reference

- **File**: `crates/p2a-core/tests/validation_ml_advanced.rs`
- **Tests**:
  - `test_validate_c50_classification` - Single tree accuracy > 0.80
  - `test_validate_c50_boosted` - 10-trial boosted accuracy > 0.80
  - `test_validate_c50_predict` - Out-of-sample accuracy > 0.70

## Tolerance

- Training accuracy: > 0.80 (separable synthetic data)
- Out-of-sample accuracy: > 0.70
- Variable importance: signal features (x1, x2) > noise (x3)

## Target types and missing values

- **Target.** `run_c50` (and `ml_c50`) takes non-negative integer class codes from an
  integer or decimal column, or a text, categorical or boolean column. Labels become the
  codes 0..K-1 in R `factor()` order (text in byte order, which is R's order under
  `LC_COLLATE=C`; FALSE < TRUE) and are reported in `C50Result::class_names` (JSON
  `class_names`, `null` for a numeric target) and a "Class labels: 0 = no, 1 = yes" line of
  the Display. Predictions, rules and `class_labels` stay codes; rules still name
  features by index (ML-144, Tier 4).
- **Missing values.** A missing value (null or NaN) in the target or a feature is an
  error naming the column (Fail; p2a's trees have no surrogate splits). `±Inf` is refused
  as well.
- **Tests.** `test_na_c50_class_labels`, `test_na_extract_x_classes_levels`,
  `test_na_ml_wrappers_int64_target_equals_float64` and
  `test_na_ml_wrappers_refuse_missing_values` (`crates/p2a-core/src/ml/extract.rs`),
  `test_na_mcp_tree_tools_integer_and_missing_targets` and
  `test_mcp_c50_ctree_text_targets` (`crates/p2a-mcp/src/tools/handlers/ml.rs`). They
  compare p2a with p2a (a text target against the same classes as integer codes) and pin
  no R number.
