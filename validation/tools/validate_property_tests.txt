# Format, one per line:  <test id> | <kind> | <reason>
#   test id: as in validation/methods/*.json (<package>::<libtest path> or <package>::<test binary>::<name>)
#   kind:    formula  - a published or hand-derived reference value; the R package is not installed
#            exact    - an exact identity of the input (no estimation)
#            property - a stated property that no R function returns
