# test_validate_* tests that compare with no committed R case and keep that name on purpose (X-10).
# Format, one per line:  <test id> | <kind> | <reason>
#   test id: as in validation/methods/*.json (<package>::<libtest path> or <package>::<test binary>::<name>)
#   kind:    formula  - a published or hand-derived reference value; the R package is not installed
#            exact    - an exact identity of the input (no estimation)
#            property - a stated property that no R function returns
#            quoted   - compares R output quoted in the test source (the R call is in its comment),
#                       not a committed case; it does not count as R-pinned
#            registered-property - a registered test that loads its case but compares no R value
#                       (properties on R's data); it does not count as R-pinned
#   reason:  why the test keeps its test_validate name (at least 20 characters)
# A test of kind formula, exact, property or quoted is never listed in validation/methods/*.json;
# a registered-property test always is. Prefer renaming a DGP check to *_recovers_dgp.
